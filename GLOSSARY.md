# Календарь звонков

Сервис персонального бронирования: один владелец публикует типы встреч и доступное время, гости записываются на слоты.

## Language

### Акторы

**Владелец**:
Человек, который ведёт календарь: заводит типы встреч, задаёт доступные для планирования даты и время, просматривает брони.
_Avoid_: Организатор, администратор, пользователь

**Гость**:
Человек, который записывается на встречу: выбирает тип встречи и слот, оставляет свои данные.
_Avoid_: Клиент, участник, записавшийся

### Понятия

**Тип встречи**:
Серия встреч, которую ведёт владелец; у неё есть название, описание и длительность, которую задаёт владелец.
_Avoid_: Событие, звонок, тип события

**Слот** (слот времени):
Непрерывный временной отрезок, длительность которого равна длительности типа встречи; в один слот можно записать одного гостя.
_Avoid_: Окошко, таймслот, время

**Бронь**:
Факт записи гостя на конкретный слот конкретного типа встречи. Одновременно у гостя не больше одной предстоящей брони на тип встречи, и его предстоящие брони не пересекаются по времени.
_Avoid_: Запись, событие; «бронирование» — это процесс, а не бронь
